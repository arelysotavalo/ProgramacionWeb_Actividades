# Perfil Profesional - Emanuel Alejandro Jácome Pineda

## Descripción del proyecto

Este proyecto consiste en el desarrollo de un sitio web personal para presentar el perfil profesional de Emanuel Alejandro Jácome Pineda, mediante una interfaz organizada, visualmente atractiva y adaptable a diferentes dispositivos.

El sitio permite conocer información personal, formación académica, habilidades, intereses profesionales y proyectos desarrollados. Además, incorpora herramientas de navegación y un formulario de contacto para facilitar la interacción con los visitantes.

## Objetivos

- Desarrollar una página web que permita presentar información académica y profesional.
- Organizar el contenido mediante secciones claramente identificadas.
- Implementar una galería visual para mostrar proyectos realizados.
- Facilitar la navegación entre las diferentes secciones.
- Incorporar un formulario de contacto con validaciones.

## Tecnologías utilizadas

- **HTML5:** estructura y organización del contenido.
- **CSS3:** diseño, estilos visuales, distribución y adaptabilidad de la página.
- **Git:** control de versiones del proyecto.
- **GitHub:** almacenamiento y colaboración en el desarrollo.

## Funcionalidades implementadas

### 1. Presentación profesional
- Información personal y académica.
- Formación académica.
- Habilidades y conocimientos.
- Intereses profesionales.

### 2. Galería de proyectos
- Presentación visual de los proyectos desarrollados.
- Imágenes representativas.
- Títulos y descripciones de cada proyecto.
- Distribución organizada mediante CSS Grid.

### 3. Navegación
- Menú de navegación entre las diferentes secciones.
- Barra lateral con posicionamiento dinámico.
- Desplazamiento suave entre secciones.

### 4. Formulario de contacto
- Campo para ingresar el nombre.
- Campo para el correo electrónico.
- Área para escribir mensajes.
- Validación de los campos mediante atributos HTML.
- Efectos visuales e interacciones mediante CSS.

### 5. Footer
- Información académica y personal.
- Referencias de contacto.
- Información de derechos de autor.

## Instalación y ejecución

1. Clonar el repositorio:

   ```bash
   git clone https://github.com/arelysotavalo/ProgramacionWeb_Actividades.git
   ```

2. Ingresar a la carpeta del proyecto:

   ```bash
   cd perfil-profesional
   ```

3. Abrir el archivo `index.html` en un navegador web.


## Colaboración y control de versiones

El desarrollo del proyecto se realiza mediante Git y GitHub, utilizando ramas, commits, Issues y Pull Requests para organizar las actividades y facilitar la integración de los cambios realizados por los integrantes.

Cada funcionalidad se desarrolla de manera independiente y posteriormente se revisa antes de integrarse a la rama principal.
